# AuraGen — Biotech Animated Landing Page

This repository contains a premium, animation-driven biotechnology landing page built as a submission for the "Round 1 — Creative Frontend Developer" assessment. The objective of this project is to demonstrate strong frontend development, creative design, responsive implementation, and modern interaction design.

The final goal was to create a website that feels like a premium, real-world biotechnology company website, avoiding generic templates or standard portfolio formats.

---

## 🚀 Tech Stack

This project was built utilizing modern frontend technologies focused on clean, maintainable code, optimized assets, and smooth performance:

- **Framework:** Next.js / React
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion / GSAP

---

## 🛠 Setup & Installation Instructions

Follow these steps to get the project running locally on your machine.

### Prerequisites

Ensure you have **Node.js 18.x or higher** installed on your machine.

### Step-by-Step Setup

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Jozz77/auragen.git
   cd auragen
   ```

2. **Install dependencies:**

   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Run the development server:**

   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. **View the project:**

   Open [http://localhost:3000](http://localhost:3000) in your browser to inspect the application. The page auto-updates as you edit the source files.

## 🎨 Design & Animation Approach

### Design Philosophy

- **Original Visual Identity:** The project features an original visual identity with a high-tech dark theme, avoiding direct copying of inspiration references.
- **Structured Content Hierarchy:** Built with modern typography and a clear visual hierarchy. It includes all mandated sections: Hero Section (with headline, CTA, and biotech visuals), About/Innovation, Technology/Research, Capabilities/Services, Statistics/Impact, and a Final CTA.
- **Fully Responsive:** The layout dynamically adapts across viewports, offering custom-tailored interfaces for desktop, tablet, and mobile devices.
- **Accessibility & UX:** Focus was placed on accessible design, clean component architecture, and fast load performance.

### Animation & Interaction Strategy

- **Scroll-Driven Animations:** Utilizes locked viewport sticky-scroll mechanics and state transitions to step through complex technical data sequentially.
- **Tactile Micro-Interactions:** Includes micro-interactions and smooth scrolling to deliver an engaging, tactile user experience.
- **Interactive Scientific Visuals:** Features custom interactive biotech elements (such as sequence decoders, folding sliders, and simulation canvases) to reflect real-world molecular engineering workflows.
